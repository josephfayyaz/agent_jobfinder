PHASE UX3 — Unified Entry Point
================================

## Goal

One command starts the complete stack. The user never needs to know about uvicorn,
worker.py, docker compose, or conda — just:

```bash
python -m job_agent.cli start
```

or alternatively:

```bash
./run.sh
```

**Depends on:** UX1 (settings YAML) must exist. UX2 (onboarding) should have been run.

## Files to Create

### 1. `job_agent/cli_start.py`  (NEW — start command implementation)

A Python module that:

1. **Preflight checks** — fail fast with clear messages:
   - Docker daemon running? (`docker info 2>/dev/null`)
   - DB container running? (`docker exec local-llm-db pg_isready -U job_agent`)
     - If not: auto-start it with `docker compose up -d db` and wait up to 10s
   - `config/user_settings.yml` exists? If not, print onboarding reminder and exit.
   - Port 8000 free? If occupied, ask "Server already running? Open browser? [Y/n]"
   - LM Studio reachable (warning only, don't block)

2. **Launch processes** as subprocesses (not threads):
   ```python
   import subprocess, sys, signal, time, webbrowser, os
   from pathlib import Path

   PYTHON = str(Path(sys.executable))  # uses whichever python is active

   procs = []

   def start():
       # DB
       subprocess.run(["docker", "compose", "up", "-d", "db"], check=True)
       _wait_for_db()

       # API server
       api = subprocess.Popen([
           PYTHON, "-m", "uvicorn",
           "job_agent.main:app",
           "--host", "0.0.0.0",
           "--port", "8000",
           "--reload",
       ])
       procs.append(api)

       # Worker
       worker = subprocess.Popen([PYTHON, "-m", "job_agent.worker"])
       procs.append(worker)

       _wait_for_api()
       webbrowser.open("http://localhost:8000/ui")

       print("[Job Agent] Running. Press Ctrl+C to stop all services.")

       def _shutdown(sig, frame):
           print("\n[Job Agent] Shutting down...")
           for p in procs:
               p.terminate()
           sys.exit(0)

       signal.signal(signal.SIGINT, _shutdown)
       signal.signal(signal.SIGTERM, _shutdown)

       # Keep alive — exit if either child dies
       while True:
           for p in procs:
               if p.poll() is not None:
                   print(f"[Job Agent] Process {p.pid} exited. Shutting down.")
                   _shutdown(None, None)
           time.sleep(2)
   ```

3. **`_wait_for_db()`** — poll `docker exec local-llm-db pg_isready` up to 15 attempts, 1s apart.
4. **`_wait_for_api()`** — poll `GET http://localhost:8000/health` up to 20 attempts, 1s apart.
   Show Rich spinner while waiting.
5. Rich output throughout (not raw print):
   - `[✓] DB ready` / `[✗] DB failed`
   - `[✓] API server up at http://localhost:8000`
   - `[✓] Worker started`
   - `[→] Opening browser...`

## Onboarding Gate

If `config/user_settings.yml` is missing:
```
[!] Not configured yet.

Run the setup wizard first:
    python -m job_agent.onboard

Then start:
    python -m job_agent.cli start
```
Exit with code 1.

---

## Graceful Shutdown Contract

On Ctrl+C (SIGINT) or SIGTERM:
1. Send SIGTERM to uvicorn and worker subprocesses.
2. Wait up to 5s for each to exit.
3. SIGKILL any that haven't exited.
4. Print "[Job Agent] All services stopped."

Do NOT `docker compose down db` — the DB should keep running between restarts (named volume persists data).

## Conventions

- Never use `os.system()`. Always use `subprocess.Popen` or `subprocess.run`.
- The PYTHON path from `sys.executable` ensures the correct conda env is used.
- Do not hardcode `<home>/` anywhere.
- Run `pytest --tb=short -q` and `ruff check` after implementation.
- Write report to `AGENT_SPECS/completed/phase_UX3_report.md`.
- Append to `completed_agent_specs.txt`.
