PHASE UX5 — Settings Web UI (Provider Switcher)
================================================

## Goal

Upgrade `/ui/settings` from a read-only config dump to a functional settings editor.
Users can switch LLM providers, update model names, change thresholds, and test connections
— all from the browser without touching `.env` or YAML files directly.

**Depends on:** UX1 (`POST /settings/save` and `GET /settings/current` endpoints must exist).

---

## What the New Settings Page Shows

Four collapsible sections (use `<details>/<summary>` or Alpine.js x-show):

### 1. LLM Provider
- Radio group: Local (LM Studio) / OpenAI / Anthropic / Mixed
- LM Studio URL field + "Test Connection" button
- Model dropdowns for small/writer/mid — populated by `GET /lm-studio/models`
- OpenAI API key (password input, masked, shows "***" if set)
- Anthropic API key (password input, masked, shows "***" if set)
- Connection status badges: ● Online / ○ Offline for each configured provider

### 2. Job Discovery
- Target seniority: radio buttons (intern / junior / mid / senior / any)
- Minimum match score: slider (50-100)
- Enable JobSpy: toggle
- Discovery location: text input
- Discovery queries: textarea (one per line → saved as list)

### 3. CV Thresholds
- CV pass score: slider (60-100)
- CV revise score: slider (40-90)
- Bullet word limit: number input

### 4. System
- Default Candidate ID (read-only, shown for reference)
- "Re-ingest Fact Sheet" button (existing functionality, keep it)
- "Reload Settings" button — calls `POST /settings/reload`

## Backend Additions

### `GET /lm-studio/models` (NEW endpoint in main.py)

```python
@app.get("/lm-studio/models")
def lm_studio_models():
    """Proxy GET /v1/models from LM Studio. Returns list of model IDs."""
    try:
        response = httpx.get(f"{settings.lm_studio_base_url}/models", timeout=3)
        if response.is_success:
            data = response.json()
            return {"models": [m["id"] for m in data.get("data", [])], "online": True}
    except Exception:
        pass
    return {"models": [], "online": False}
```

### `POST /settings/reload` (ADD to main.py)

```python
@app.post("/settings/reload")
def settings_reload():
    """Re-apply user_settings.yml overlay to the in-process settings singleton."""
    from job_agent.config import load_user_settings_overlay, settings as s
    load_user_settings_overlay(s)
    return {"status": "reloaded"}
```

### Update `GET /ui/settings` route

Replace the current config_pairs read-only approach with:

```python
@app.get("/ui/settings", include_in_schema=False)
def ui_settings(request: Request):
    from job_agent.user_config import read_user_settings, EDITABLE_FIELDS
    user_yml = read_user_settings()

    # LM Studio model list
    lm_models = []
    lm_online = False
    try:
        r = httpx.get(f"{settings.lm_studio_base_url}/models", timeout=2)
        if r.is_success:
            lm_models = [m["id"] for m in r.json().get("data", [])]
            lm_online = True
    except Exception:
        pass

    return TemplateResponse(
        request=request,
        name="settings.html",
        context={
            "title": "Settings",
            "current": {f: getattr(settings, f, None) for f in EDITABLE_FIELDS},
            "lm_models": lm_models,
            "lm_online": lm_online,
            "openai_configured": bool(settings.openai_api_key),
            "anthropic_configured": bool(settings.anthropic_api_key),
            "candidate_id": settings.default_candidate_id,
            "yaml_exists": Path("config/user_settings.yml").exists(),
        },
    )
```

<script>
async function saveSection(formId, fields) {
  const form = document.getElementById(formId);
  const data = {};
  for (const field of fields) {
    const el = form.elements[field];
    if (!el || el.value === "") continue;
    const v = el.value.trim();
    // jobspy_discover_queries: textarea → split into list
    if (field === "jobspy_discover_queries") {
      data[field] = v.split("\n").map(s => s.trim()).filter(Boolean);
    } else if (["match_min_score","cv_pass_score","cv_revise_score","bullet_clarify_word_limit"].includes(field)) {
      data[field] = parseInt(v);
    } else {
      data[field] = v;
    }
  }
  const resp = await fetch("/settings/save", {
    method: "POST",
    headers: {"Content-Type": "application/json"},
    body: JSON.stringify(data),
  });
  const status = document.getElementById(formId.replace("-form", "-status")) || document.getElementById("system-status");
  if (resp.ok) {
    if (status) status.textContent = "✓ Saved";
    setTimeout(() => { if (status) status.textContent = ""; }, 3000);
  } else {
    if (status) status.textContent = "✗ Save failed";
  }
}

async function testLmStudio() {
  const url = document.querySelector('[name="lm_studio_base_url"]').value;
  const resp = await fetch(`/lm-studio/models`);
  const data = await resp.json();
  const el = document.getElementById("provider-status");
  el.textContent = data.online ? `✓ Online — ${data.models.length} models` : "✗ LM Studio not reachable";
}

async function reloadSettings() {
  const resp = await fetch("/settings/reload", {method: "POST"});
  document.getElementById("system-status").textContent = resp.ok ? "✓ Reloaded" : "✗ Failed";
}
</script>

def test_ui_settings_returns_200(client):
    response = client.get("/ui/settings")
    assert response.status_code == 200
    assert "LLM Provider" in response.text
    assert "Job Discovery" in response.text

def test_lm_studio_models_endpoint_offline(client, monkeypatch):
    import httpx
    monkeypatch.setattr(httpx, "get", lambda *a, **kw: (_ for _ in ()).throw(Exception("down")))
    response = client.get("/lm-studio/models")
    assert response.status_code == 200
    assert response.json()["online"] is False
    assert response.json()["models"] == []

def test_settings_reload_endpoint(client):
    response = client.post("/settings/reload")
    assert response.status_code == 200
    assert response.json()["status"] == "reloaded"

def test_settings_save_and_page_reflects_new_value(client, tmp_path, monkeypatch):
    from job_agent import user_config
    monkeypatch.setattr(user_config, "USER_SETTINGS_PATH", tmp_path / "us.yml")
    client.post("/settings/save", json={"target_job_seniority": "senior"})
    response = client.get("/ui/settings")
    assert "senior" in response.text
