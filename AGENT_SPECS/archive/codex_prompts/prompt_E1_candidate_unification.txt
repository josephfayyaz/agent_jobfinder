2. job_agent/services/workflows.py — add _candidate_profile_dict():

   Build the SAME dict shape as _profile_dict() but sourced from Candidate + its
   FK-linked fact tables. Use this mapping:

   full_name        ← candidate.full_name
   email            ← candidate.email or ""
   phone            ← ""   (not stored on Candidate; leave blank)
   location         ← ""   (not stored on Candidate; leave blank)
   linkedin_url     ← ""
   github_url       ← ""
   public_brand_summary ← ""
   global_skills    ← candidate.skills_json.get("skills", []) if skills_json else []
   experiences      ← [
                         {
                           "role_title": e.role_title,
                           "company": e.company or "",
                           "start_date": e.start_date or "",
                           "end_date": e.end_date or "",
                           "bullets": e.verified_core_facts or [],
                           "tools": e.tools_and_tech or [],
                         }
                         for e in session.query(ExperienceFact)
                                         .filter_by(candidate_id=candidate.id)
                                         .order_by(ExperienceFact.display_order)
                                         .all()
                       ]
   projects         ← [
                         {
                           "name": p.project_name,
                           "summary": p.short_resume_line or "",
                           "tools": p.tools_and_tech or [],
                         }
                         for p in session.query(ProjectFact)
                                         .filter_by(candidate_id=candidate.id)
                                         .all()
                       ]
   education        ← [
                         {
                           "degree": ed.degree or "",
                           "institution": ed.institution or "",
                           "year": ed.graduation_year or "",
                         }
                         for ed in session.query(EducationFact)
                                          .filter_by(candidate_id=candidate.id)
                                          .all()
                       ]
   certifications   ← []
   achievements     ← []
   additional_notes ← {}

   NOTE: Check the actual column names on ExperienceFact, ProjectFact, EducationFact
   in models.py — use the REAL names. Key ones:
     ExperienceFact: .role_title, .verified_core_facts, .tools_and_tech
     ProjectFact:    .project_name, .short_resume_line, .tools_and_tech
   If a column referenced above doesn't exist on the model, skip it silently.
