# Phase UI1 — Draft Detail Viewer (/ui/drafts/{id})

## Goal

Add a full-page detail view for each CV draft. Currently `/ui/drafts` shows only a
summary table with no way to inspect the actual CV content, compliance matrix, or
trigger a bullet rewrite from the browser.

This page is the primary review + approval screen before the user applies to a job.

---

## Hard Rules

- No Alembic. Never create venvs. Always conda ML.
- Starlette TemplateResponse: keyword args only.
  `TemplateResponse(request=request, name="x.html", context={...})` — positional args crash.
- No new ORM models or DB schema changes required.
- All new template files go in `job_agent/templates/`.

---

**Existing endpoints used by this page:**

## What to Implement

### 1. New route in `job_agent/main.py`

```python
@app.get("/ui/drafts/{draft_id}", include_in_schema=False)
def ui_draft_detail(draft_id: UUID, request: Request, db: Session = Depends(get_db)):
    draft = db.get(ResumeDraft, draft_id)
    if draft is None:
        raise HTTPException(status_code=404, detail="Draft not found.")
    job = db.get(JobPost, draft.job_post_id)
    track = db.get(ResumeTrack, draft.resume_track_id)
    return templates.TemplateResponse(
        request=request,
        name="draft_detail.html",
        context={
            "draft": draft,
            "job": job,
            "track": track,
            "content": draft.content or {},
            "review_feedback": draft.review_feedback or {},
            "compliance_matrix": (draft.review_feedback or {}).get("compliance_matrix"),
            "ranked_keywords": (draft.review_feedback or {}).get("ranked_keywords") or [],
        },
    )
```

Place this route immediately after the existing `@app.get("/ui/drafts", ...)` endpoint.

### 3. New template `job_agent/templates/draft_detail.html`

Full layout:
```
┌─ Header ─────────────────────────────────────────────────────────┐
│  [← Back to CVs]  Job Title @ Company  Track badge  Score badge  │
│  Status pill  Provider label  [Approve] [Reject] [PDF] buttons   │
└──────────────────────────────────────────────────────────────────┘

┌─ Main grid (2 columns on xl screens) ───────────────────────────┐
│ Left col (wider):                Right col (sidebar):           │
│  • Professional Summary          • Compliance Matrix card       │
│  • Experiences + bullets         • Ranked Keywords list         │
│  • Projects + bullets            • Suggestions (if any)        │
│  • Skills tags                                                  │
└─────────────────────────────────────────────────────────────────┘

┌─ Cover Letter section ──────────────────────────────────────────┐
│  [Generate Cover Letter] button → HTMX loads partial below      │
└─────────────────────────────────────────────────────────────────┘
```

**Header section:**
- Back link: `<a href="/ui/drafts">← Back to CVs</a>`
- Title: `{job.title} @ {job.company}` (or "Unknown job" if job is None)
- Score badge: green ≥75, yellow ≥50, red <50 (reuse same Tailwind classes as drafts.html)
- Status pill: same color logic
- Approve button: `hx-post="/ui/drafts/{draft.id}/approve"` + `hx-on::after-request="window.location.reload()"` — hide if already approved
- Reject button: same pattern — hide if already rejected or approved
- PDF button: `<a href="/drafts/{draft.id}/pdf" target="_blank">` — only if draft.tex_path

**Compliance Matrix card (right sidebar):**
- If `compliance_matrix` is set in context:
  - Show `coverage_pct`% as a colored progress bar (green ≥80, yellow ≥50, red <50)
  - List `requirements` as a table: coverage icon (✓ strong, ~ partial, ✗ missing) + requirement text
  - Show strong_count, partial_count, missing_count summary counts
- If `compliance_matrix` is None:
  - Show a "Generate Matrix" button:
    ```html
    <button
      hx-post="/drafts/{{ draft.id }}/compliance-matrix"
      hx-swap="none"
      hx-on::after-request="window.location.reload()"
      class="px-3 py-1.5 text-sm bg-indigo-600 text-white rounded hover:bg-indigo-700"
    >
      Generate Compliance Matrix
    </button>
    ```

**Ranked Keywords (right sidebar):**
- Show only if `ranked_keywords` is non-empty
- List top 10 keywords as colored badges: priority="high" → indigo, "medium" → slate, "low" → gray
- Each badge shows `keyword (frequency)`

**Professional Summary:**
- `<p>{{ content.professional_summary }}</p>`
- If empty: grey italic "No summary generated."

**Experiences:**
- For each in `content.selected_experiences`:
  - Title + company + date range as header
  - Bullet list for each bullet in `experience.bullets`

**Projects:**
- For each in `content.selected_projects`:
  - Project name as header
  - Bullet list

**Skills:**
- Render `content.selected_skills` as tags (same indigo badge style as ranked_keywords)

**Cover Letter section (bottom):**
- Button: `hx-post="/drafts/{{ draft.id }}/cover-letter-html"` `hx-target="#cl-detail"` `hx-swap="outerHTML"`
- Empty div below with `id="cl-detail"`

## Tests

File: `tests/test_ui_draft_detail.py`

### Test 1 — page returns 200 with draft data
```python
def test_ui_draft_detail_returns_200(client, db_session, db_job, db_track):
    from uuid import uuid4
    from job_agent.models import ResumeDraft
    draft = ResumeDraft(
        id=uuid4(), job_post_id=db_job.id, resume_track_id=db_track.id,
        provider="test", status="drafted", score=80.0,
        content={"professional_summary": "Test summary", "selected_skills": ["Python"],
                 "selected_experiences": [], "selected_projects": []},
        review_feedback={}, tex_path="",
    )
    db_session.add(draft)
    db_session.commit()

    response = client.get(f"/ui/drafts/{draft.id}")

    assert response.status_code == 200
    assert "Test summary" in response.text
```
