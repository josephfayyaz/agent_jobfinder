# start_apply — Urgent Standalone CLI Tool

## Purpose

A completely standalone CLI tool (no FastAPI, no DB required) that lets the user
paste messy job information, get a match score against their fact sheet, answer up
to 3 clarifying questions, and receive a tailored CV file — all from the terminal.

This exists separately from the main FastAPI app so it can be used immediately
without starting any services, and it produces output files the user can submit.

---

## Hard Rules

- No Alembic, no FastAPI, no DB dependency.
- Uses conda ML env: `/Users/youseffayyaz/miniforge3/envs/ML/bin/python`
- Reuses `job_agent.llm.LLMRouter` and `job_agent.config.settings` from the
  existing package — do NOT duplicate LLM call logic.
- Never fabricate skills. Only use facts the user confirms.
- Each rewritten bullet must be ≤ 22 words.

## Step-by-Step Flow

### Step 1: Load job info
- If `--input` given: read file
- Else: print `"Paste job info below (title, company, URL, JD, anything you have)."` +
  `"Press Enter twice then Ctrl+D when done:"` and read from stdin until EOF

### Step 2: Parse job info (job_parser.py)
LLM call (role="small") to extract structured data from messy text.

System prompt:
```
You are extracting structured job information from raw text. The user may have
pasted a job description, a URL, a company name, or any combination. Extract
what you can. Return valid JSON only. Use null for fields you cannot determine.
```

User prompt:
```
Extract job information from the following raw text:

{raw_text}

Return JSON:
{
  "title": "...",
  "company": "...",
  "location": "...",
  "url": "... or null",
  "description": "full job description text",
  "requirements": ["requirement 1", "requirement 2", ...],
  "nice_to_have": ["nice to have 1", ...],
  "seniority": "junior|mid|senior|intern|unknown"
}
```

Print: `"\n[1/4] Parsed: {title} at {company} ({location})"`

### Step 3: Score match (scorer.py)
LLM call (role="small") comparing job requirements to fact sheet content.

Load fact sheet: read the full text file at the resolved path.
Truncate fact sheet to 4000 chars if longer (use the first 4000 chars).

System prompt:
```
You are a resume match analyst. Score how well a candidate's background matches
a job description. Be honest and precise. Return valid JSON only.
```

User prompt:
```
JOB: {title} at {company}
SENIORITY: {seniority}

JOB REQUIREMENTS:
{requirements joined by newline}

CANDIDATE FACT SHEET (excerpt):
{fact_sheet[:4000]}

Score the match 0-100.
- 85-100: Strong match, apply directly
- 60-84: Good match, some gaps — clarification may help
- 0-59: Weak match, significant gaps

Return JSON:
{
  "score": <int 0-100>,
  "matched": ["skill/experience that clearly matches"],
  "gaps": ["requirement with no clear evidence in fact sheet"],
  "summary": "2-sentence honest assessment"
}
```

Print:
```
[2/4] Match score: {score}/100
      Matched: {matched[:3] joined by ", "}
      Gaps: {gaps joined by ", " or "None"}
      {summary}
```

If score >= 85: print `"Strong match. Proceeding to CV generation..."` and skip Step 4.
If score < 30: print warning `"Low match ({score}/100). CV will reflect confirmed facts only."` and continue.

### Step 4: Clarifying questions (questioner.py) — only if gaps exist
Only runs if `len(gaps) > 0`. Generate up to 3 questions.

LLM call (role="small"):

System prompt:
```
Generate specific yes/no clarifying questions to find out if the candidate has
evidence for skill gaps. Each question must be answerable with "yes + metric"
or "no". Ask only if a positive answer would justify a resume bullet.
Return valid JSON only.
```

User prompt:
```
JOB: {title} at {company}
GAPS (skills in JD with no match in fact sheet): {gaps}
FACT SHEET EXCERPT: {fact_sheet[:2000]}

Generate at most 3 clarifying questions.
Return JSON:
{
  "questions": [
    {
      "id": "q1",
      "gap": "...",
      "question": "Have you [specific thing]? If yes, give a brief result or metric.",
      "why": "This matters because [JD context]"
    }
  ]
}
```

For each question, interactively ask the user:
```
[Question 1/3]
Gap: {gap}
Question: {question}
Why it matters: {why}
Your answer (or press Enter to skip): _
```

Collect answers. An empty answer = skip (confirmed=False).
A non-empty answer = confirmed=True with the answer text.

Print: `"[3/4] Answers recorded. Generating CV..."`

### Step 5: Generate CV (cv_writer.py)

LLM call (role="writer"):

System prompt:
```
You are a professional resume writer. Write a tailored CV section using only
confirmed facts. Rules:
- Use the company's exact language from the job description.
- Each bullet must be ≤ 22 words.
- Start each bullet with a strong past-tense action verb.
- Include at least one metric per bullet where possible.
- NEVER fabricate skills or outcomes. If the user said "no" to a question, omit that skill.
- Vary your verbs. Do not start two bullets with the same word.
Return valid JSON only.
```

User prompt:
```
JOB: {title} at {company}
LOCATION: {location}
SENIORITY: {seniority}

JOB REQUIREMENTS:
{requirements}

CANDIDATE FACT SHEET:
{fact_sheet[:4000]}

CONFIRMED ADDITIONAL FACTS (from clarifying questions):
{for each confirmed answer: "- {gap}: {answer}"}
{for each skipped/no answer: "- {gap}: NOT CONFIRMED — omit this skill"}

MATCH ANALYSIS:
{summary}
Matched: {matched}

Generate a tailored CV. Return JSON:
{
  "headline": "job title variant matching the role",
  "professional_summary": "3-4 sentence summary using company language, ≤80 words",
  "key_skills": ["skill1", "skill2", ...],
  "experience_bullets": [
    {
      "role": "role title from fact sheet",
      "company": "company from fact sheet",
      "bullets": ["bullet 1", "bullet 2", ...]
    }
  ],
  "project_bullets": [
    {
      "name": "project name",
      "bullets": ["bullet"]
    }
  ],
  "tailoring_notes": ["note about why this CV matches the role"]
}
```

Post-process: enforce 22-word limit on all bullets (truncate at last complete word).

### Step 6: Save output

Determine output filename:
- Sanitise company name: lowercase, spaces to underscores, remove special chars
- Filename: `start_apply/output/{company}_{date}.md`
- Date format: YYYY-MM-DD

Write a markdown file:
```markdown
# CV — {title} at {company}
**Generated:** {datetime}
**Match Score:** {score}/100
**Location:** {location}

---

## {headline}

{professional_summary}

---

## Key Skills
{key_skills as bullet list}

---

## Experience
{for each role: ## Role at Company, then bullet list}

---

## Projects
{for each project: ### Project Name, then bullet list}

---

## Tailoring Notes
{tailoring_notes as bullet list}

---
*Generated by start_apply CLI. Verify all facts before submitting.*
```

Print:
```
[4/4] CV saved to: start_apply/output/{filename}

Summary:
  Score:    {score}/100
  Company:  {company}
  Role:     {title}
  Bullets:  {total bullet count}
  Output:   start_apply/output/{filename}
```

If LM Studio is not running, catch ProviderUnavailableError and print:
```
ERROR: LM Studio is not running. Start LM Studio and load a model, then retry.
Ensure the writer model is loaded (the larger one) for best results.
```

## cli.py (main entry point)

```python
#!/usr/bin/env python3
"""
start_apply — quick CLI to generate a tailored CV from messy job info.

Usage:
    python start_apply/cli.py
    python start_apply/cli.py --input ~/job_info.txt
    python start_apply/cli.py --input ~/job_info.txt --fact-sheet ~/path/to/fact_sheet.txt
"""
import argparse
import sys
from pathlib import Path

DEFAULT_FACT_SHEET = Path("/Users/youseffayyaz/Polito/Resume-CV/fact_sheet/master_fact_sheet.txt")

def main():
    parser = argparse.ArgumentParser(description="Generate a tailored CV from job info.")
    parser.add_argument("--input", type=Path, help="Path to a text file with job info.")
    parser.add_argument("--fact-sheet", type=Path, default=None, help="Path to your fact sheet.")
    args = parser.parse_args()

    # Resolve fact sheet
    import os
    fact_sheet_path = args.fact_sheet or Path(os.environ.get("FACT_SHEET_PATH", str(DEFAULT_FACT_SHEET)))
    if not fact_sheet_path.exists():
        print(f"ERROR: Fact sheet not found at {fact_sheet_path}")
        print("Set --fact-sheet or FACT_SHEET_PATH env var.")
        sys.exit(1)

    # Load raw job input
    if args.input:
        raw_text = args.input.read_text(encoding="utf-8")
    else:
        print("Paste job info below (title, company, URL, JD — anything you have).")
        print("Press Enter twice then Ctrl+D when done:\n")
        lines = []
        try:
            for line in sys.stdin:
                lines.append(line)
        except KeyboardInterrupt:
            print("\nCancelled.")
            sys.exit(0)
        raw_text = "".join(lines).strip()
        if not raw_text:
            print("No input provided. Exiting.")
            sys.exit(1)

    fact_sheet = fact_sheet_path.read_text(encoding="utf-8")

    # Run pipeline
    from start_apply.job_parser import parse_job_info
    from start_apply.scorer import score_match
    from start_apply.questioner import ask_clarifying_questions
    from start_apply.cv_writer import generate_cv, save_cv

    print("\nProcessing...\n")

    job = parse_job_info(raw_text)
    result = score_match(job, fact_sheet)
    confirmed_facts = []
    if result["gaps"]:
        confirmed_facts = ask_clarifying_questions(result["gaps"], job, fact_sheet)
    cv = generate_cv(job, fact_sheet, result, confirmed_facts)
    output_path = save_cv(cv, job, result["score"])
    print(f"\n[4/4] CV saved to: {output_path}")
    print(f"\nSummary:\n  Score:   {result['score']}/100\n  Company: {job['company']}\n  Role:    {job['title']}\n  Output:  {output_path}")

if __name__ == "__main__":
    main()
```
