# Spec C8 — Offer Evaluation and Negotiation

## Goal

Extend Job Agent from search/apply into decision support once the main pipeline is mature.

## Build

1. Offer record
   - company
   - salary
   - location
   - remote policy
   - visa/relocation notes
   - growth notes

2. Comparison view
   - compare offers side by side
   - score by user priorities

3. Negotiation prep
   - evidence-based negotiation bullets
   - questions to ask before accepting

4. Constraint model
   - allow user priorities:
     - compensation
     - location
     - learning
     - visa / relocation
     - work-life balance

## UX

Decision support should stay simple and pragmatic.

## Success Metric

- users can compare offers clearly
- stronger decision quality after the search stage
