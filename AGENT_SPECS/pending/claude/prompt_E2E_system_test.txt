# E2E System Test Plan — Pre-Shipping QA

**Context:** The system is feature-complete (292 tests). This spec adds a full
end-to-end acceptance test suite that walks every user-facing workflow from
start to finish, covering both the API and the UI. All unit tests already pass.
These new tests prove the system works as a product, not just as code.

Deliver: `tests/test_e2e_full_journey.py` (automated) + `tests/MANUAL_TEST_CHECKLIST.md`
(step-by-step browser + terminal acceptance script).

---

## Hard Rules

- No Alembic. Always conda ML.
- Do NOT add mocks for happy-path API tests — use the TestClient with a real in-memory
  SQLite/test DB (as the existing conftest.py sets up). Only mock the LLM router
  and external HTTP calls (ATS APIs, Gmail).
- Every automated test must be independent — no shared state between tests.
- The manual checklist must be runnable by someone who has never seen this codebase.
  Write every step as an explicit command or browser action.

---

def test_manual_job_creation_and_cv_queue(client, db_track):
    """
    Full journey: add a job manually → queue CV → verify draft is created.
    Uses TestClient so no real LLM needed (monkeypatched).
    """
    # Step 1: Create a job via API
    response = client.post("/jobs", params={
        "source_name": "manual",
        "source_url": "https://acme.example.com/jobs/99",
        "canonical_apply_url": "https://acme.example.com/jobs/99",
        "company": "AcmeCorp",

        "status": "new",

    job_id = response.json()["id"]

### 8. Velocity Spike Alert (time-filter regression)

```python
def test_velocity_spike_only_returns_recent_logs(client, db_session, monkeypatch):
    """check_velocity_spikes must NOT return old logs. Regression for B5."""
    from datetime import datetime, timedelta, timezone
    from job_agent.models import CareerPageScanLog, CareerPageSource
    from job_agent.services.career_scanner import CareerPageScanner
    from job_agent.config import settings

    monkeypatch.setattr(settings, "velocity_spike_threshold", 3)
    source = CareerPageSource(
        company="SpikeCo", career_url="https://spikeco.example.com",
        country="Italy", active=True,
    )
    db_session.add(source)
    db_session.commit()

    # Old log — 4 hours ago
    old_log = CareerPageScanLog(source_id=source.id, jobs_found=10, new_jobs=8)
    db_session.add(old_log)
    db_session.commit()
    old_log.scanned_at = datetime.now(timezone.utc) - timedelta(hours=4)
    db_session.commit()

    spikes = CareerPageScanner().check_velocity_spikes(db_session)
    assert not any(s["company"] == "SpikeCo" for s in spikes), (
        "Old log (4h ago) should not trigger spike alert"
    )

    # Recent log — just now
    db_session.add(CareerPageScanLog(source_id=source.id, jobs_found=10, new_jobs=8))
    db_session.commit()

    spikes = CareerPageScanner().check_velocity_spikes(db_session)
    assert any(s["company"] == "SpikeCo" for s in spikes), (
        "Recent log should trigger spike alert"
    )
```
