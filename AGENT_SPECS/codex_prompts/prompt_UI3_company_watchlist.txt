# Phase UI3 — Company Watchlist (/ui/companies)

## Goal

Add a browser UI to manage the `CareerPageSource` watchlist — the companies whose job
boards the worker scans automatically. Currently the only way to add/view companies is
via raw API calls (`POST /career-pages`, `GET /career-pages`).

This page lets Yousef:
- See all watched companies with their ATS type, last scan time, new-jobs count
- Toggle a company active/inactive with one click
- Add a new company directly from the browser
- Trigger an immediate scan for a specific company

---

## Hard Rules

- No Alembic. Never create venvs. Always conda ML.
- Starlette TemplateResponse keyword args only.
- No new ORM models or DB schema changes required.
- VALID_ATS_TYPES = `["greenhouse", "lever", "ashby"]` — enforce in the toggle endpoint.

**Existing API endpoints (already in main.py):**
```
GET  /career-pages                        → list all sources
POST /career-pages                        → create (params: company, career_url, country,

```

`POST /career-pages` validates `ats_type`:
- If provided, must be one of `["greenhouse", "lever", "ashby"]` → 400 otherwise.
- `ats_slug` required when `ats_type` is set.

## What to Implement

### 1. New toggle-active endpoint in `job_agent/main.py`

Place after `GET /career-pages` endpoint:

```python
@app.post("/career-pages/{source_id}/toggle-active", status_code=204)
def toggle_career_page_active(source_id: int, db: Session = Depends(get_db)):
    source = db.get(CareerPageSource, source_id)
    if source is None:
        raise HTTPException(status_code=404, detail="Career page source not found.")
    source.active = not source.active
    db.add(source)
    db.commit()
    return Response(status_code=204)
```

### 2. New UI route in `job_agent/main.py`

Place after the toggle endpoint:

```python
@app.get("/ui/companies", include_in_schema=False)
def ui_companies(request: Request, db: Session = Depends(get_db)):
    sources = (
        db.query(CareerPageSource)
        .order_by(CareerPageSource.active.desc(), CareerPageSource.company.asc())
        .all()
    )
    return templates.TemplateResponse(
        request=request,
        name="companies.html",
        context={
            "sources": sources,
            "ats_types": ["greenhouse", "lever", "ashby"],
        },
    )
```

Note: `hx-post="/career-pages"` sends query params not form body — but FastAPI's
`POST /career-pages` uses `Query()` params, so append them as URL params:
Change to:
```html
hx-post="/career-pages"
hx-vals='js:{
  "company": document.querySelector("[name=company]").value,
  ...
}'
```
Actually this is complex. Simpler: use a regular HTML `<form method="post" action="/career-pages">` with `?`-encoded params via `enctype="application/x-www-form-urlencoded"`. But FastAPI reads these as Query params, not form body.

**Correct approach**: Use HTMX `hx-include` with a hidden form + JS param builder, OR simply use a regular form with action built dynamically. The easiest approach that works with FastAPI Query params:

```html
<form
  id="add-company-form"
  class="bg-white rounded-lg shadow p-4 mb-4 flex flex-wrap gap-3 items-end text-sm"
  onsubmit="submitAddCompany(event)"
>
  <!-- inputs as above -->
  <button type="submit" class="px-3 py-1.5 bg-green-600 text-white rounded">Add</button>
</form>
<script>
function submitAddCompany(e) {
  e.preventDefault();
  const f = e.target;
  const params = new URLSearchParams({
    company: f.company.value,
    career_url: f.career_url.value,
    country: f.country.value || 'Italy',
  });
  if (f.ats_type.value) params.set('ats_type', f.ats_type.value);
  if (f.ats_slug.value) params.set('ats_slug', f.ats_slug.value);
  fetch('/career-pages?' + params.toString(), {method: 'POST'})
    .then(r => { if (r.ok || r.status === 201) window.location.reload(); else r.json().then(d => alert(d.detail)); });
}
</script>
```

### Test 2 — toggle-active flips the active flag
```python
def test_toggle_active_flips_flag(client, db_session):
    from job_agent.models import CareerPageSource
    source = CareerPageSource(
        company="TestCo",
        career_url="https://testco.example.com/jobs",
        country="Italy",
        active=True,
    )
    db_session.add(source)
    db_session.commit()
    db_session.refresh(source)

    response = client.post(f"/career-pages/{source.id}/toggle-active")
    assert response.status_code == 204

    db_session.refresh(source)
    assert source.active is False

    # toggle back
    client.post(f"/career-pages/{source.id}/toggle-active")
    db_session.refresh(source)
    assert source.active is True
```

### Test 3 — toggle-active returns 404 for unknown source
```python
def test_toggle_active_returns_404_for_unknown(client):
```
