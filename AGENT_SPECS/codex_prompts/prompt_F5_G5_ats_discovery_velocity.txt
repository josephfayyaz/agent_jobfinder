# Phase F5+G5 — Zero-Token ATS Discovery + Posting Velocity Alerts

## Goal

F5: When a company uses Greenhouse, Lever, or Ashby as their ATS, call their
public JSON API directly (no browser, no LLM tokens) to discover jobs. This is
faster and cheaper than the existing HTML career page scraper.

G5: After each scan, record how many new jobs appeared per company. When a
company suddenly has a spike (≥ 3 new jobs in one scan), log a WARNING so the
worker output surface it. Expose velocity data via a new endpoint.

Both features extend the existing `CareerPageSource` model — no new tables for
company tracking, just new columns and a new scan log table.

---

## Hard Rules

- No Alembic. All schema changes go in `prepare_database()` in `db.py`.
- Always conda ML.
- No shared DB sessions across threads.
- If an ATS API call fails (HTTP error, timeout), fall back to the existing HTML scraper.
- The new AtsApiScanner must call its own `SessionLocal()` per thread, same as the existing parallel scanner.
- Never break existing career page scan behaviour. The HTML scraper remains the default.

## ATS API URLs (for reference)

| ATS | API URL pattern | What it returns |
|---|---|---|
| Greenhouse | `https://boards-api.greenhouse.io/v1/boards/{slug}/jobs` | `{"jobs": [{id, title, location.name, absolute_url}]}` |
| Lever | `https://api.lever.co/v0/postings/{slug}?mode=json` | `[{id, text, hostedUrl, categories.location}]` |
| Ashby | `https://jobs.ashbyhq.com/api/non-user-facing/job-board/details/{slug}` | `{"jobPostings": [{id, title, locationName, jobPostingUrl}]}` |

All are public, unauthenticated GET requests. Use `httpx` (already in project).
Timeout: 10 seconds. User-Agent: same `_HEADERS` as career_scanner.py.

## 1. New Service `AtsApiScanner`

Create `job_agent/services/ats_scanner.py`:

```python
"""Zero-token ATS API scanner for Greenhouse, Lever, and Ashby."""

import httpx

_TIMEOUT = 10.0
_HEADERS = {
    "User-Agent": "Mozilla/5.0 (compatible; job-agent-scanner/1.0)",
    "Accept": "application/json",
}

class AtsApiScanner:
    """Fetches job listings directly from ATS public JSON APIs."""

    def fetch_jobs(self, ats_type: str, ats_slug: str) -> list[dict]:
        """
        Returns list of dicts: [{title, url, location}]
        Raises httpx.HTTPError on failure (caller handles fallback).
        """
        if ats_type == "greenhouse":
            return self._fetch_greenhouse(ats_slug)
        if ats_type == "lever":
            return self._fetch_lever(ats_slug)
        if ats_type == "ashby":
            return self._fetch_ashby(ats_slug)
        raise ValueError(f"Unknown ats_type: {ats_type}")

    def _fetch_greenhouse(self, slug: str) -> list[dict]:
        url = f"https://boards-api.greenhouse.io/v1/boards/{slug}/jobs"
        resp = httpx.get(url, headers=_HEADERS, timeout=_TIMEOUT)
        resp.raise_for_status()
        data = resp.json()
        return [
            {
                "title": job["title"],
                "url": job["absolute_url"],
                "location": (job.get("location") or {}).get("name") or "",
            }
            for job in data.get("jobs", [])
        ]

    def _fetch_lever(self, slug: str) -> list[dict]:
        url = f"https://api.lever.co/v0/postings/{slug}?mode=json"
        resp = httpx.get(url, headers=_HEADERS, timeout=_TIMEOUT)
        resp.raise_for_status()
        data = resp.json()
        return [
            {
                "title": job.get("text", ""),
                "url": job.get("hostedUrl", ""),
                "location": (job.get("categories") or {}).get("location") or "",
            }
            for job in (data if isinstance(data, list) else [])
        ]

    def _fetch_ashby(self, slug: str) -> list[dict]:
        url = f"https://jobs.ashbyhq.com/api/non-user-facing/job-board/details/{slug}"
        resp = httpx.get(url, headers=_HEADERS, timeout=_TIMEOUT)
        resp.raise_for_status()
        data = resp.json()
        return [
            {
                "title": job.get("title", ""),
                "url": job.get("jobPostingUrl", ""),
                "location": job.get("locationName") or "",
            }
            for job in data.get("jobPostings", [])
        ]
```

## 3. G5 — Velocity Detection

After `scan_all()` / `scan_all_parallel()` completes, check for velocity spikes.

Add method `check_velocity_spikes(session) -> list[dict]` to `CareerPageScanner`:

```python
def check_velocity_spikes(self, session: Session) -> list[dict]:
    """
    Return sources where latest scan had new_jobs >= velocity_spike_threshold.
    """
    from job_agent.config import get_settings
    threshold = get_settings().velocity_spike_threshold
    logs = (
        session.query(CareerPageScanLog)
        .filter(CareerPageScanLog.new_jobs >= threshold)
        .order_by(CareerPageScanLog.scanned_at.desc())
        .limit(20)
        .all()
    )
    spikes = []
    for log in logs:
        source = session.get(CareerPageSource, log.source_id)
        spikes.append({
            "company": source.company if source else "unknown",
            "new_jobs": log.new_jobs,
            "scanned_at": log.scanned_at.isoformat(),
            "career_url": source.career_url if source else "",
        })
    return spikes
```

In `worker.py`, after each career scan cycle, call `check_velocity_spikes()`:
```python
spikes = CareerPageScanner().check_velocity_spikes(session)
for spike in spikes:
    logger.warning(
        "VELOCITY SPIKE: %s added %d new jobs at %s — apply soon!",
        spike["company"], spike["new_jobs"], spike["scanned_at"]
    )
```

### New endpoint `GET /analytics/posting-velocity`

```python
@app.get("/analytics/posting-velocity")
def posting_velocity(days: int = 7, db: Session = Depends(get_db)):
    """
    Return recent scan logs grouped by company, showing velocity over last N days.
    """
    cutoff = datetime.now(timezone.utc) - timedelta(days=days)
    logs = (
        db.query(CareerPageScanLog)
        .filter(CareerPageScanLog.scanned_at >= cutoff)
        .order_by(CareerPageScanLog.scanned_at.desc())
        .all()
    )
    # Group by source_id, aggregate new_jobs, return sorted by total new_jobs desc
    from collections import defaultdict
    grouped = defaultdict(lambda: {"new_jobs": 0, "scans": 0, "last_scan": None})
    for log in logs:
        source = db.get(CareerPageSource, log.source_id)
        if not source:
            continue
        key = source.company
        grouped[key]["company"] = source.company
        grouped[key]["career_url"] = source.career_url
        grouped[key]["ats_type"] = source.ats_type
        grouped[key]["new_jobs"] += log.new_jobs
        grouped[key]["scans"] += 1
        if grouped[key]["last_scan"] is None or log.scanned_at > grouped[key]["last_scan"]:
            grouped[key]["last_scan"] = log.scanned_at
    result = sorted(grouped.values(), key=lambda x: x["new_jobs"], reverse=True)
    return {"days": days, "companies": result}
```
