PHASE UX4 — CLI Command Suite
==============================

## Goal

A `job-agent` CLI (using click + rich) so users can manage the system from the terminal
without navigating folders or knowing API endpoints. The CLI talks to the running server
via HTTP — it does not import job_agent business logic directly.

**Depends on:** UX1 (settings layer), UX3 (cli.py group already exists with `start` command).

---

## Libraries

- `click` — commands and options
- `rich` — tables, panels, color output
- `httpx` — HTTP calls to localhost:8000
- `questionary` — interactive prompts for guided flows

---

## Entry Point Registration

In `setup.cfg` or `pyproject.toml` add:

```toml
[project.scripts]
job-agent = "job_agent.cli:cli"
```

Then `pip install -e .` (in conda ML) makes `job-agent` available system-wide.

---

## Command Tree

```
job-agent
  start                   # UX3 — start full stack
  onboard                 # UX2 — run setup wizard
  status                  # quick health check
  apply                   # guided job application
  companies
    list                  # list watched companies
    add                   # guided add
    toggle <id>           # toggle active/inactive
    remove <id>           # confirm + delete
  settings
    show                  # print current settings
    set <key> <value>     # write a single field to user_settings.yml
    reload                # POST /settings/reload
```

## Implementation: `job_agent/cli.py`

### Helper: API client

```python
import httpx
from rich.console import Console

console = Console()
BASE_URL = "http://localhost:8000"

def _api(method: str, path: str, **kwargs):
    try:
        response = httpx.request(method, f"{BASE_URL}{path}", timeout=30, **kwargs)
        response.raise_for_status()
        return response
    except httpx.ConnectError:
        console.print("[red]Cannot reach server at localhost:8000.[/red]")
        console.print("Run [bold]job-agent start[/bold] first.")
        raise SystemExit(1)
    except httpx.HTTPStatusError as e:
        console.print(f"[red]API error {e.response.status_code}:[/red] {e.response.text[:200]}")
        raise SystemExit(1)
```

### `job-agent apply`

Interactive guided flow:

1. Check server is running.
2. Prompt: "Enter a job URL or paste job description text: "
3. If URL: POST `/jobs/add` with the URL → get job_id.
4. If text: POST `/jobs/from-text` with raw text (add this endpoint if missing — see below).
5. Show job match score if available.
6. Ask: "Generate CV draft for this job? [Y/n]"
7. If yes: POST `/drafts/generate` with job_id → poll until done → show score.
8. Ask: "Open draft in browser? [Y/n]"
9. If yes: `webbrowser.open(f"http://localhost:8000/ui/drafts/{draft_id}")`.

Note: if `POST /jobs/from-text` doesn't exist, create a stub endpoint in main.py:
```python

    # role_title extracted by small LLM from first 200 chars, or "Unknown Role" fallback.
    ...
```

Add `DELETE /career-pages/{id}` endpoint in main.py if it doesn't exist:
```python
@app.delete("/career-pages/{source_id}", status_code=204)
def delete_career_page(source_id: int, db: Session = Depends(get_db)):
    source = db.get(CareerPageSource, source_id)
    if not source:
        raise HTTPException(404)
    db.delete(source)
    db.commit()
```

```bash

→ Updated target_job_seniority = mid
→ Reload server to apply? [Y/n]: y
→ POST /settings/reload
✓ Settings reloaded
```

Calls `POST /settings/save` with `{key: value}`.
If value is "true"/"false", convert to bool before sending.
If value is numeric, convert to int before sending.

## Conventions

- All CLI output uses `rich.console.Console`, never raw `print()`.
- Server offline → clear message + hint to run `job-agent start`.
- Interactive prompts use `questionary` with sensible defaults.
- Do NOT import SQLAlchemy or job_agent services in cli.py — HTTP only.
- Run `pytest --tb=short -q` and `ruff check` after implementation.
