PHASE I2 — Italy Tech Companies Seed + Job Role Limit
======================================================

## Goal

Two related improvements:

1. **Seed 50 top tech companies in Italy** into `CareerPageSource` on first run — so new
   users have a real watchlist immediately instead of an empty table.

2. **Enforce a max of 5 job roles** in `jobspy_discover_queries` — prevent users from
   adding unlimited queries that bloat the settings and slow down discovery.

```python
def seed_italy_companies(session) -> int:
    """Insert companies not already in the DB. Returns count of new rows inserted."""
    from job_agent.models import CareerPageSource
    existing_urls = {
        row.career_url
        for row in session.query(CareerPageSource.career_url).all()
    }
    new_count = 0
    for entry in ITALY_TECH_COMPANIES:
        if entry["career_url"] in existing_urls:
            continue
        source = CareerPageSource(
            company=entry["company"],
            career_url=entry["career_url"],
            country=entry["country"],
            ats_type=entry.get("ats_type"),
            ats_slug=entry.get("ats_slug"),
            active=True,
        )
        session.add(source)
        new_count += 1
    if new_count:
        session.commit()
    return new_count
```

### Call from `db.py` — `prepare_database()`

At the end of `prepare_database()`, after all `ALTER TABLE` calls:

```python
def prepare_database() -> None:
    ...
    # Seed Italy companies on first run (idempotent — skips existing URLs)
    from job_agent.seed_companies import seed_italy_companies
    with SessionLocal() as _seed_session:
        count = seed_italy_companies(_seed_session)
        if count:
            logger.info("Seeded %d Italy tech companies into watchlist.", count)
```

This runs once at startup and is fully idempotent — existing companies are never duplicated.

## Part B: Job Role Limit (max 5)

### In `job_agent/user_config.py`

Change the `EDITABLE_FIELDS` type for `jobspy_discover_queries`:

No change needed to type — it stays `list`. Enforce max in the save endpoint.

### In `job_agent/main.py` — `settings_save` endpoint

Add validation:

```python
if "jobspy_discover_queries" in sanitized_updates:
    queries = sanitized_updates["jobspy_discover_queries"]
    if isinstance(queries, list) and len(queries) > 5:
        raise HTTPException(
            status_code=422,
            detail="Maximum 5 job discovery roles allowed. Remove some before adding more."
        )
```

### In `job_agent/templates/settings.html`

Add a character counter hint under the discovery queries textarea:

```html
<p class="mt-2 text-xs text-slate-400">
  One role per line. <strong>Maximum 5 roles.</strong>
  Current: <span id="role-count">0</span>/5.
</p>
```

And a JS snippet to count lines:

```javascript
document.querySelector('[name="jobspy_discover_queries"]').addEventListener('input', function() {
  const count = this.value.split('\n').filter(l => l.trim()).length;
  document.getElementById('role-count').textContent = count;
  if (count > 5) this.style.borderColor = 'rgb(239,68,68)';
  else this.style.borderColor = '';
});
```

```python
def test_seed_italy_companies_idempotent(db_session):

    seed_italy_companies(db_session)
    count2 = seed_italy_companies(db_session)
    assert count2 == 0  # nothing new inserted
```
