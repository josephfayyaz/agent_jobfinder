Help

How the workspace runs

The setup gate exists so discovery, matching, and CV drafting only start after the app has one trusted provider and one usable profile.

What you need first

Your full name and email, one CV or profile note, one active AI provider, one country, and up to four target roles.

Provider model

The app uses one provider for the whole workflow at a time. If you select LM Studio, only LM Studio is used. If you switch to OpenAI or Claude later, future intake, scoring, discovery analysis, and CV work follow that provider instead.

AI provider keys

OpenAI and Claude API keys come from their developer consoles, not from normal chat subscriptions.

OpenAI API keys Anthropic API keys

Search rules

Your target roles, seniority, language preferences, and single-country focus shape discovery, matching, and fit scoring. The app shows provider-scored jobs separately from jobs still awaiting enrichment.

Manual targets

If you already have a job description or job URL, paste it into the Jobs screen to see the match score, strengths, and gaps first. Adding that target to the queue is optional, not automatic.

Queue lanes

New for you is the active review lane. Awaiting enrichment holds jobs that still need stronger descriptions before they can be scored honestly. Shortlist, Save for later, and Not for me are your personal triage lanes.

CV preview vs export

Preview stays inside the app or opens in a browser tab. Download PDF is a separate action so you can review the draft before exporting the final file.
