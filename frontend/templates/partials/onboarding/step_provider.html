OpenAI API

Use a cloud key only if you want the whole workflow to run through OpenAI.

Cloud credits required

How to get it

  1. Create a key at platform.openai.com/api-keys.
  2. Add billing if needed at OpenAI billing.

A ChatGPT subscription does not include API credits.

Google Gemini API

Use Gemini only if you want the workflow to run through Google’s hosted Gemini API.

Cloud credits required

How to get it

  1. Create a key in Google AI Studio.
  2. Keep the key local on this machine and only use it if you want remote inference.

Anthropic API

Use Claude only if you want the whole workflow to run through Anthropic.

How to get it

  1. Create a key at console.anthropic.com.
  2. Add API credits in Anthropic billing if needed.
