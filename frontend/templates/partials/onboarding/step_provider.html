Recommended local setup

  • Use one loaded chat model for the whole app. Job Agent will reuse that same local model for intake, drafting, and review.
  • Prefer smaller reliable models first: 7B to 14B instruct/chat models, or `gpt-oss-20b` if your machine handles it comfortably.
  • Set the LM Studio context window to at least 16k. 24k+ is better for larger CV or fact-sheet inputs.
