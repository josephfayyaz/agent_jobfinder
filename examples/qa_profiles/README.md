Synthetic QA profiles for deterministic end-to-end testing.

These fact sheets are intentionally complete and evidence-rich so the CV pipeline
can be tested against realistic candidate shapes without using personal data.

Profiles included:
- `consultant_profile.json`
- `tech_profile.json`
- `finance_profile.json`
- `sales_profile.json`
- `operations_profile.json`

Each file follows the canonical fact sheet schema used by
`job_agent.services.fact_sheet_json.FactSheetJsonIngestionService`.
